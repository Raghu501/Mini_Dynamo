# Mini Dynamo

Mini Dynamo is a lightweight, in-memory database designed for simplicity and ease of use. It provides basic functionalities for storing and retrieving data, making it ideal for small applications and testing purposes.

## Installation

To install the required dependencies, run the following command:

```
pip install -r requirements.txt
```

## Usage

To run the application, use the following command:

```
python -m mini_dynamo
```

You can also import the `mini_dynamo` package in your Python scripts to use its functionalities.
